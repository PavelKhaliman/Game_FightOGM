# Звук

Необязательные WAV: `menu`, `round`, `start`, `hit`, `heavy`, `kick`, `block`,
`special`, `ultimate`, `ko`, `victory`, `counter`.

Положите, например, `heavy.wav` в эту папку. Игра загрузит его при следующем запуске.
Для отсутствующих эффектов используются встроенные синтезированные сигналы.
Необязательный музыкальный трек — `music.ogg`, воспроизводится по кругу.
Без аудиоустройства игра продолжает работать без звука.
